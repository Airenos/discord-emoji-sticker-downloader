# Discord Emoji & Sticker Downloader 📥

一个轻量级、本地优先的油猴脚本，用于一键批量导出当前账号已加入并可访问的 Discord 服务器内的自定义表情包 (Emojis) 和贴纸 (Stickers)，并整理打包为 `.zip` 文件下载到本地！

---

## ✨ 核心特性

- 🎨 **批量导出表情** — 一键获取服务器内的全部静态表情 (PNG) 与动态表情 (GIF)。
- 🎟️ **批量导出贴纸** — 完整支持高清贴纸导出（自动识别并保存为 PNG、APNG、GIF 或 Lottie JSON）。
- 🖼️ **原生拟物 UI** — 定制下拉选择菜单，完整支持服务器高清头像显示与动态加载指示器（Spinner）。
- 📦 **极速 ZIP 打包** — 优化打包流程，无需复杂二次压缩，秒级生成压缩包，全程无卡顿。
- 🖐️ **防遮挡任意拖拽** — 右下角的“📥 Emojis”下载按钮支持自由拖拽与边界吸附，彻底告别遮挡输入框烦恼。
- 🌐 **多语言特殊字符支持** — 打包生成的压缩文件完美支持带有中文、日文、韩文等特殊字符的服务器名称。
- 🔓 **纯净开源透明** — 无任何付费限制、无第三方遥测统计，所有逻辑均在本地浏览器内完成。

---

## 🛡️ 隐私与安全说明

- **本地安全运行**：本脚本完全在您的本地浏览器中运行。为了获取服务器元数据，脚本会在本地复用您当前 Discord Web 网页端已登录的 Session 会话凭证请求 Discord 原生 API。
- **绝无数据外泄**：脚本代码**绝不会**将您的任何 Token 或隐私信息上传到作者服务器或任何第三方统计平台。
- **平台风险提醒**：Discord 官方条款禁止在官方 Bot/OAuth2 API 之外对普通用户账号进行自动化调用。本工具仅供个人备份与离线收藏使用，请自行评估使用风险并遵守 Discord 用户守则。
